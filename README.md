Dashboard JSMS (Job Safety Management System) berbasis **React** untuk **PT Elefanteinfradigi Solution**.

## 📋 Fitur
✅ **Login Aman** - Username: `afizhasyim1@gmai.com` | Password: `1234566`  
✅ **Dashboard Lengkap** dengan:  
   - 4 KPI Cards (Total Jobs, Incidents, Compliance, Workers)
